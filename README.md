# Autonomous Server Bot (CPRE 288 Final)

Embedded C code for an autonomously-navigating resturaunt server bot with real-time manual control, field-scan analysis, and on-the-fly object detection and avoidance in resturaunt-based environments.

## Dependencies

- iRobot Open Interface
- TivaWare TM4C123GH6PM Architecture

## Build

The files provided in this project rely on the build features provided in Code Composer Studio to compile source code to Open Interface iRobot devices. As such, it is recommended that you clone or download this repository manually and compile the code yourself. The latest working build for this repository can be found in the `master` branch of this repository.
